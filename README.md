# Jai Dhingra · Portfolio

Dashboard-style portfolio of 31 AI and automation builds, grouped by function (Admin, Sales, Recruitment, Marketing, Legal).

Built with Vite, React, TypeScript, Tailwind v4 and motion.

## Run locally

```bash
npm install
npm run dev
```

## Deploy (Vercel)

- Framework preset: Vite
- Build command: `npm run build`
- Output directory: `dist`

Routing is hash-based (`/#/build/<id>`), so no rewrites are needed.
